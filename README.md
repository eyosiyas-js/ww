# CIMS Project

This repository contains the frontend and backend services for CIMS.

## Project Structure

- `front1/`: Frontend application (React, Vite, TypeScript, Tailwind CSS)
- `master_api/`: Backend service (FastAPI, SQLAlchemy, Alembic)

## Getting Started

### Frontend (`front1`)
```bash
cd front1
npm install
npm run dev
```

### Backend (`master_api`)
```bash
cd master_api
pip install -r requirements.txt
python run_server.py
```
